# Firmware executable source provenance and public boundary

This directory and src/veriforge/firmware executable/harness/job/driver files are original VerifForge implementation sources. They contain a curated bad STATUS header and a hand-authored one-line correction; no model-generated repair or executed firmware is claimed. Public source authorization does not imply an explicit open-source license grant: this checkout currently has no project-root LICENSE file. Main owns any project licensing decision; do not invent a license for original project files.

The externally authored execution dependency is the unmodified upstream PicoRV32 RTL at targets/riscv/upstream/picorv32.v, revision ef203c2b0a3fb793280f5114941416c425c5b461, Git blob cc45fa998f1857b06a856ea59b931f6c37e06b34, SHA2560836050971b3c6cdd28ac3b1e5719a67fb645161912bef1e472e63995ceb0622. Its ISC notice remains in the file header. targets/riscv/upstream.json records repository, revision, checksums and role; targets/riscv/picorv32_top.sv is the project's existing wrapper reused read-only.

Spike is not used to reference this MMIO peripheral. Its separate RAM-only tool baseline and BSD-3-Clause license remain documented at targets/riscv/upstream.json and targets/riscv/upstream/SPIKE-LICENSE; the latter is included as provenance context, not a firmware runtime dependency. GCC/binutils, Verilator and cocotb are external tools and are not vendored by this source closure; retain their installed versions/image hashes and upstream notices in the eventual execution image. Python packages are declared in pyproject.toml with uv.lock retained; no package/license reclassification or installation occurs here.

Pure owner and independent review tests establish only source preparation, parsing, protocol checking and adversarial evidence rejection. Their fake bus traces, synthetic ELF and scheduler must remain labelled as such. The project's actual hosted RAM-only RISC-V evidence must not be attributed to firmware/MMIO. Actual control/bad/candidate firmware execution, disassembly review, reset/all-register-zero checks, ELF repeatability, saved-binary replay, evidence export and public runtime acceptance remain separate gates.

The exact source-only closure and hashes are recorded by main's U5-PUBLIC-CLOSURE receipt. It includes explicit source/test/docs/config dependencies, not .coordination, .artifacts, local databases, environments, credentials, generated objects/ELF, build output or private evidence. Existing accepted dependencies stay read-only. A focused commit needs only new firmware implementation/fixture/test/provenance files; shared accepted dependencies should not be staged incidentally.
