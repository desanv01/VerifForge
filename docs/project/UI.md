# Local investigation workbench (VF-070A)

The React/Vite/TypeScript application lives in `apps/web`. Run `npm ci`, then `npm run dev` there. Vite binds loopback only at `http://127.0.0.1:5173`; `/api` proxies to the Compose runtime at `http://127.0.0.1:18000`. Set `VERIFORGE_API_PROXY` before starting Vite to select another local API (for example standalone uvicorn on port 8000). Port 18000 avoids an unrelated service already using port 8000 on this machine. See API.md for backend migrations and worker setup. No public deployment is configured.

The initial flow reads installed curated projects and the immutable reviewed FIFO contract, requires acknowledgement of the active semantics, creates a bounded typed reset-boundary experiment draft, then explicitly starts it. It can cancel active execution, restore a campaign from `?campaign=<id>`, and inspect persisted event history, status, verdict, first finding, bounded transaction trace, evidence hashes, actual tool versions, artifacts and uncertainties. TanStack Query owns server state and polls active campaigns every 1.5 seconds; saved campaign lists refresh every 5 seconds. This slice uses the documented JSON polling fallback rather than SSE. Event history currently displays the API's first bounded page (200 events); transaction display is capped at 200 samples.

An unchanged failed draft submission retains its idempotency key and exact payload for a manual retry. Start/cancel requests carry an idempotency key and rely on server transition semantics. Draft creation requires a reviewed contract; the checkbox acknowledges existing semantics and does not change the server contract review status.

Execution completion and checker verdict appear separately. A timeout has explicit non-defect wording. Unavailable API, empty catalog, contract errors, loading, queued work, missing evidence, unsupported execution, and unconnected model planning remain visible. No preview fixtures or fabricated results are substituted. The curated experiment uses no model call. Its fixed stimulus is reset(2), write(17), reset(1), write(42), read, under 100 cycles / a user-selected wall-time limit (default 120 seconds, integer 1–3600) / 10 MiB. The seed is an unsigned 32-bit integer (0–4294967295). The saved campaign shows its immutable submitted budget separately; changing the inputs only creates a new draft. Those are configured limits, not measured performance. Actual simulator availability is determined by worker execution; the browser does not claim capability from API health.

The API's finding envelope is `{id,attempt_id,status,verdict,result,contract_id,plan_hash}`; signature and identity come from `result`. General source editing, waveform editing, arbitrary uploads, patch application, model controls, and Vivado execution are outside this slice. Arithmetic and AXI-Lite are labeled planned.

VF-070C corrects inspection of legal 64-bit stimulus/trace integers. JSON response text passes through a dependency-free inspection decoder with a 16 × 1024 × 1024 UTF-16-character parsing limit. It validates the original JSON grammar, then preserves unsafe integral numeric lexemes (including negative/scientific forms) as strings using the unchanged source, skipping quoted strings and escapes. The initial grammar-check values are discarded when preservation is required. Ordinary safe numbers, quoted text and normal floating-point semantics remain compatible; this is not an arbitrary-precision floating-point parser. Oversized or invalid JSON fails explicitly without interpreting a result.

Saved experiment display is labeled **parsed view**, never exact/raw JSON: quoted large-number strings retain their digits but deliberately change the inspection representation. Trace data fields accept these preserved strings and render their digits directly. Use server evidence bytes for a raw record and the no-body server replay action for an exact replay; do not copy the inspection representation into a new request. Mutation serialization rejects unsafe integer numbers, non-finite numbers and bigint at any nested JSON field before fetch. Safe input requests and the existing bodyless replay protocol remain unchanged. Focused mocked HTTP/render tests and typecheck evidence are recorded in `.coordination/deliveries/VF-070C.md`; no live execution is inferred from those tests.

VF-070B wires the VF-022 evidence endpoints documented in API.md. Controls require `/api/health` to advertise `status: "ok", evidence_api: "1"`, a complete five-hash attempt identity, and a successful authorized artifact list. Older servers leave controls disabled with an explanation. UI IDs are database attempt IDs (`campaign.attempts[].id`). Portable artifact downloads use the authorized `artifact_id`; other paths remain metadata only. Errors such as changed/missing evidence remain inline and do not navigate away from the campaign.

Exact replay immediately queues a new campaign using the saved plan, seed, budget and identities; it calls no model and never mutates the original. The UI selects the returned campaign with a null/in-flight verdict. Replay retries after a lost response retain their request key. Export creation queues a durable job; the UI polls queued/running status, supports cancellation, and offers a download only after completed status and published hash/size. Failed/cancelled jobs can create a fresh request. Export IDs persist in the campaign URL as `?campaign=...&export=...`; a restored export must match the selected attempt. Unchanged failed export requests retain their key. Binary downloads are fetched only after a click and use local temporary object URLs with generated filenames, never server-provided filesystem paths.

The VF-070B delivery report separates tests using mocked HTTP from actual backend/browser evidence. A health capability is a protocol marker, not proof of a working simulator or successful export. A queued replay does not establish reproduction. During implementation, the baseline runtime on port 18000 lacks VF-022 until the controlled API rebuild; evidence commands stay disabled there.

The design is entirely local, per the user's instruction relayed by main. The required 12ui skill was read, but hosted draft failed under sandbox networking and an escalation was rejected before execution because it would disclose the internal brief. The human then explicitly chose local-only implementation. No hosted design assets are used. Native semantic controls, visible focus, a skip link, accessible table caption, status/error announcements, reduced-motion support, and stacked mobile layout form the initial accessibility baseline. System fonts avoid external requests.

Validation commands: `npm run test`, `npm run typecheck`, `npm run build`, `npm audit`. Test fixtures are mocked HTTP unit/integration tests only; they are not simulator or model evidence. Actual observed validation and browser limitations are recorded in `.coordination/deliveries/VF-070A.md`.
